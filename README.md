# STARTUP_IR

기업 자료를 근거로 편집 가능한 투자유치 IR PPT를 만드는 범용 템플릿 모음입니다.

## 템플릿 선택

| 템플릿 | 구성 | 사용 안내 |
|---|---|---|
| **SEQUOIA 기업별 브랜드 IR** | 본편 10장 + 선택 부록 4장, 기업 원본 IR의 대표색·이미지 적용 | [시작하기](STARTUP_IR/templates/sequoia_brand_ir/README.md) |
| 기존 딥그린 IR | 16:9, 초록색 기반 12장 | [기존 안내](STARTUP_IR/README.md) |

SEQUOIA 양식의 순서는 Company Purpose → Problem → Solution → Why Now? → Market Potential → Competition / Alternatives → Business Model → Team → Financials → Vision입니다. Sequoia Capital의 공식 배포·인증 템플릿이 아닌 자체 제작 양식입니다.

## 빠른 시작

1. [편집 가능한 빈 PPT](STARTUP_IR/templates/sequoia_brand_ir/SEQUOIA_IR_기업별색상_빈양식_v2.pptx)를 내려받습니다.
2. [제작 워크플로우](STARTUP_IR/templates/sequoia_brand_ir/01_IR_제작_워크플로우.md)와 기업 원본 자료를 함께 사용합니다.
3. 기업의 원본 IR에서 대표색을 확인하고, 검증된 정보와 원본 이미지를 넣습니다.
4. 실적·계획·가정·미확인 값을 구분하고 완성 PPT를 검수합니다.

내 GPT에는 [GPT 지침](STARTUP_IR/templates/sequoia_brand_ir/03_GPT_지침.txt)과 제작 워크플로우를 사용합니다. Codex용으로는 [재사용 템플릿 스킬](skills/artifact-template-sequoia-ir/SKILL.md)이 포함되어 있습니다. 설치 방법은 [템플릿 안내](STARTUP_IR/templates/sequoia_brand_ir/README.md)를 참고하세요.

## 공개 범위

이 저장소에는 범용 빈 양식·제작 지침·보조 도구만 올립니다. 기업 신청서·원본 IR·개인정보·계약서·비공개 재무 및 기업별 완성 자료는 별도 비공개 위치에서 관리하세요. `.gitignore`는 파일 내용의 비밀 여부를 판별하지 않으므로 업로드 전 파일 목록과 내용을 확인해야 합니다.
