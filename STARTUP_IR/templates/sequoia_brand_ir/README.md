# SEQUOIA 기업별 브랜드 IR

기업의 원본 IR·신청서·사업계획서를 근거로 제작하는 **16:9 편집 가능한 빈 PPT**와 재사용 워크플로우입니다. 특정 기업의 실제 정보·수치·이미지는 포함하지 않습니다.

## 포함 파일

| 파일 | 용도 |
|---|---|
| [빈 PPT 14장](SEQUOIA_IR_기업별색상_빈양식_v2.pptx) | 본편 10장과 선택 부록 4장, 편집 가능한 도형·표·차트 |
| [사용 안내](00_사용안내.txt) | 전체 사용 순서 |
| [제작 워크플로우](01_IR_제작_워크플로우.md) | 자료 분석 → 대표색 결정 → 구성 → 제작 → 검수 |
| [기업자료 입력양식](02_기업자료_입력양식.md) | 사실·출처·기준일·확인 상태 정리 |
| [GPT 지침](03_GPT_지침.txt) | 내 GPT의 Instructions에 넣을 제작 기준 |
| [색상 입력 예시](04_기업색상_입력예시.json) | 색상 역할·HEX·근거 페이지 기록 |

## 본편 순서

1. Company Purpose
2. Problem
3. Solution
4. Why Now?
5. Market Potential
6. Competition / Alternatives
7. Business Model
8. Team
9. Financials
10. Vision

표지는 첫 장에 통합되어 있습니다. 선택 부록은 원본 이미지·개발/인허가·투자/자금계획·출처/미확인 사항을 정리할 때 사용합니다. Sequoia Capital의 공식 배포·인증 양식이 아닙니다.

## 사용 기준

- 기본 네이비·블루는 교체용 색상입니다. 기업 원본 IR에서 반복되는 제목·헤더·도식 색을 확인하여 매 기업마다 바꿉니다.
- 사진·로고·연구 그림의 원본 색은 보존합니다. 대괄호 입력 슬롯은 검증된 기업 정보로 교체합니다.
- 빈 차트의 `0`은 입력 전 자리표시자입니다. 기업의 실적으로 해석하거나 그대로 발표하지 않습니다.
- 상단 섹션·결론형 제목·패널·화살표·하단 결론 띠를 활용합니다. BM 장표는 파트너–기업–고객, 수익/비용, 실행 4단계를 연결합니다.
- 실적·진행·계획·가정·미확인을 구분하고, 수치와 그림의 출처를 기록합니다. 미확인 사실을 만들어 넣지 않습니다.

## 내 GPT에서 사용

`03_GPT_지침.txt`를 지침으로, `01_IR_제작_워크플로우.md`를 참고 지식으로 사용합니다. 실제 제작 대화에는 빈 PPT와 해당 기업 자료를 첨부하고 파일 생성 기능이 있는 환경에서 PPTX 제작을 요청합니다.

예시 요청:

> 첨부 기업 자료와 이 빈 양식으로 편집 가능한 IR PPT를 만들어줘. SEQUOIA 순서를 유지하고, 대표색은 해당 기업의 원본 IR에서 확인해 적용해줘. 원본 이미지를 적절한 장표에 넣고 실적·계획·미확인 내용을 구분해줘.
