# Green IR Design System v1.0

## 브랜드 독립적 스타일

- 캔버스: 16:9 (13.333 × 7.5 inch)
- 배경: `#FFFFFF` (화이트), 보조 배경 `#F6FAF8`
- 주 색상: `#0A372D` (딥그린), `#11845D` (그린)
- 보조 색상: `#E5F4EC` (민트), `#D4E6DC` (테두리)
- 강조 색상: `#DEA53D` (주의·미완료), `#FFF1D8` (주의 배경)
- 본문 색상: `#20332C`, 설명 색상 `#5C716A`
- 폰트: Pretendard, 없으면 Noto Sans KR 또는 맑은 고딕
- 제목: 24–32pt, 본문: 12–18pt, 주석: 8–10pt

## 장표 구성 규칙

1. 제목은 **결론형 거버넌스 메시지 1개**. 기술명 나열보다 투자자 질문에 대한 답을 제시.
2. 한 장표에 **핵심 시각화 1개**, 보조 설명은 최대 3~4개.
3. 수치·도표의 단위, 기준연도, 출처는 반드시 기재.
4. 정보 구조는 **MECE**: 예를 들어 매출원과 고객군, 실적과 계획을 혼합하지 않음.
5. 가급적 명사형 개조식 표현 사용, 불필요한 문장형 설명 삭제.
6. 이미지와 아이콘은 **기능적**으로만 사용. 데이터 없는 장식성 그래프 금지.
7. 사진·생성 이미지가 실측 성과나 실물 제품을 의미하는 것처럼 오해되지 않도록 주석.

## 추천 레이아웃

- Problem: 기존 고객 여정 4~5단계 + 병목 강조
- Solution: 기존 방식 vs 자사 방식 + 핵심 작동 흐름
- Traction: 수치 2~3개 + 검증 단계/상태 + 출처
- Market: TAM/SAM/SOM 중첩 원 + 별도 성장 그래프(검증된 경우)
- BM: 고객 → 가치 → 채널 → 매출흐름, 수익원별 성격 구분
- Financial: 5개년 매출 막대 + 영업이익 선 + 가정·산식

## PPT 편집성

기본 템플릿은 **텍스트·도형·선·표 형태의 요소를 편집 가능**하게 구성. 사진과 로고는 실제 사용 권한이 있는 파일로 교체.
